# CSCI-SHU 205: Topics in Computer Science 
***
This is a repository to audit this course in order to understand Human-AI alignment and the socio-technical aspects of AI involved. 
***
### Details about this course:
1. **Instructor** : Hua Shen, Assistant Professor of Computer Science, Autumn 2025, New York University Shanghai
2. **Overview** : (taken from the program website) This course will provide an overview of (Bidirectional) Human-AI Alignment, emphasizing both how AI systems can be designed to reflect human values and how humans can be empowered to critically engage and collaborate with AI.
3. **Topics covered** : Topics include human-centered data collection and curation, reinforcement learning from human feedback (RLHF), human-in-the-loop evaluation, and human-AI interaction. By focusing on this two-way alignment, you will be equipped to shape AI systems responsibly while developing the skills to navigate and contribute to both HCI and AI research.
4. **Link to program website** : [Topics in CS – Human-AI Alignment
(CSCI-SHU 205)](https://hua-shen.org/src/course_bialign.html)

***
# Folder Structure
1. **01-foundations**: includes Overview, and Values & Morals in LLMs.
2. **02-methods**: includes Data is Gold (human-centric), Post-Training for Alignment, and Evaluation and Ecosystem.
3. **03-practice**: includes Human-AI Interaction, LLM Interpretability, and Risks, Trust and Safety.
